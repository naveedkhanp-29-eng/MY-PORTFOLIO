# Naveed Khan — Portfolio

A modern, responsive personal portfolio website for Naveed Khan, a full-stack developer and UI designer. The site presents a clean professional identity with glassmorphism styling, smooth navigation, project highlights, and contact information.

## Live Preview

Open `index.html` in a browser to view the portfolio locally.

## Contents

- Hero section with introduction and CTAs
- About section with experience and interests
- Skills section
- Featured projects section
- Contact section with social links
- Footer with branding

## Features

- Fully static HTML/CSS portfolio
- Responsive design for mobile and desktop
- Glassmorphism-inspired UI
- Animated blurred background orbs
- Smooth scrolling navigation
- Minimal dependencies and easy customization

## Local Usage

1. Open the project folder.
2. Launch `index.html` in a browser.
3. Or run a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customization

You can edit the content and styling directly inside `index.html` to change:

- Name and title
- Bio and experience text
- Skills and projects
- Social and contact links
- Colors and design details
